# Архитектура

```text
Браузер → Nginx → Gunicorn / Django → PostgreSQL
                       │
                       ├── файлы media и обработка изображений Pillow
                       ├── SMTP: коды и подтверждения
                       └── подписанный HTTP API ← Telegram worker

systemd → pg_dump + media + конфигурация → Restic → приватный S3
```

## Каталог

`Product` хранит SKU, исходные данные, перевод и рубрику витрины. Изображения, цветовые и размерные варианты вынесены в связанные модели. Адаптеры импорта приводят разные выгрузки к общей структуре; сомнительные карточки отражаются в preflight-отчёте.

`ProductImage` формирует WebP-версии для каталога и галереи. Оригиналы производственных выгрузок не поставляются в репозитории. Команда `seed_demo` создаёт независимые демонстрационные изображения без скачивания из интернета.

## Покупательские сценарии

Сессионная корзина и избранное связаны с пользовательскими данными после входа. Отложенный checkout позволяет вернуться к оформлению после авторизации. Заказы сохраняют позиции, цену, выбранные параметры и сведения о доставке. Персональные заявки используют отдельный жизненный цикл.

## Управление

Собственная панель находится в `/control/`, Django Admin — в `/admin/`. Доступ проверяется по серверной роли; чувствительные действия используют CSRF, ограничение частоты и проверку кода. Аналитика отделяет подтверждённые клиентские события от технических запросов; её посетители не равнозначны числу уникальных людей.

## Telegram

Веб-приложение отвечает за аккаунты, роли, заказы и очередь уведомлений. Отдельный worker получает данные по HTTP API. Ему не передаются реквизиты базы, SMTP или S3. Подпись HMAC-SHA256 покрывает метод, путь с query string, timestamp, nonce и хеш тела. Для изменяющих запросов предусмотрена идемпотентность.

## Границы проекта

Доставка и оплата отражаются в заказе, но реального списания средств нет. Редакторские правила исправляют известные дефекты выгрузок, а не гарантируют безошибочный перевод произвольного текста. Безопасность развёртывания зависит от настроек reverse proxy, секретов, доступа к серверу и обновлений окружения.
